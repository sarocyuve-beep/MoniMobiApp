# MoniMobiApp

Raporo y’ibikorwa by’ubukangurambaga, ubugenzuzi no gukurikirana imihigo y’Umurenge wa Cyuve, Musanze (2026–2027).

## Gukoresha

1. Kuramo `index.html` na `data.js` uzishyire mu bubiko bumwe.
2. Koresha server nto ya Python kugira ngo browser ibike raporo neza: fungura terminal muri ubwo bubiko, ukore `python -m http.server 8000`, hanyuma ujye kuri `http://localhost:8000`. Python isanzwe iza kuri mudasobwa nyinshi.
3. Uzuza raporo, uhitemo akagari n’umudugudu, umuhigo n’ubwoko bw’uruzinduko. Ibice H, I na J bigaragara hakurikijwe ubwoko bw’uruzinduko.
4. Mu gice D, hitamo kugeza ku bikorwa bitatu byo muri sheet `Ibikorwa`. Ibikorwa byunganiye urutonde byandikwa uhisemo **Byongeweho**.
5. Baseline n’intego by’umwaka/igihembwe byuzuzwa hakurikijwe umuhigo n’itariki y’uruzinduko. Igihembwe gikurikiza umwaka w’imihigo utangira muri Nyakanga (Q1: Nyakanga–Nzeri, Q2: Ukwakira–Ukuboza, Q3: Mutarama–Werurwe, Q4: Mata–Kamena).
6. Kanda **Bika raporo** kugira ngo ibikwe muri browser ikoreshwa. Raporo ziri muri browser imwe gusa; kanda **Manura JSON** kugira ngo ubike kopi yo kohereza cyangwa gusubizaho.
7. Kanda **Sohora / Bika PDF** kugira ngo ukoreshe print ya browser cyangwa ubike raporo nka PDF.

`data.js` irimo amakuru yo muri sheets zose uko ari 5: imihigo 103, ibikorwa 173 byo muri sheet `Ibikorwa`, amabwiriza, utugari 6 n’imidugudu 40. Imihigo 15 ifite ibikorwa byanditse igaragara mbere mu rutonde. Uhindura urutonde rw’imihigo, igenzura ko amakuru ahuye na V3 ya Excel.

Raporo zari zarabitswe na V2 ziguma kuri browser kandi Ref No y’umuhigo ihuzwa n’urutonde rushya igihe raporo ifunguwe.

## Ibyo raporo igenzura

- Umworozi, umukozi, itariki, ubwoko bw’uruzinduko n’igikorwa kigenzurwa.
- Nibura inama/igikorwa kimwe gifite ushinzwe n’itariki ntarengwa.
- Kuri Monitoring: findings zihariye n’umubare w’amafoto nibura umwe.
- Kuri Follow-up: nomero ya raporo y’ubushize.

Amakuru abikwa kuri iki gikoresho gusa. Ntayohererezwa kuri server.
