# GUIDELINES FOR PREPARING SAMPLE PERFORMANCE CONTRACT (IMIHIGO) REPORTS

Source: «IMIHIGO IVUGURUYE.xlsx» — system report writing guide.
Language: Kinyarwanda.
Note: These guidelines are for system design/reference. They must NOT be shown directly to employees as-is.

## Overview
- **Total goals:** 103
- **Total activities:** 889
- **Pillars/Categories:** UBUKUNGU (39 goals), IMIBEREHO MYIZA (47 goals), IMIYOBERERE MYIZA (17 goals)
- **Visit types:** Mobilization, Monitoring, Follow-up
- **Locations (Cells):** 6 — BUKINANYANA, BURUBA, CYANYA, KABEZA, MIGESHI, RWEBEYA
- **Villages:** 40 total across 6 cells

## Report Writing Rules

### Category Rule
Targets with only Mobilization or Monitoring require all applicable report types under that category. No Follow-up reports where not specified by visitTypes.

### Sheet2 Rule
Repeated works remain on Sheet2. If none repeated, the target name is used as completion example.

### Visibility Rule
Only include metrics/targets/beneficiaries/dates/names visible in source. Mark others as "not visible" or "template-based".

### General Instructions (from source)
1. Ibice A–G byuzuzwa mu bwoko bwose bw'uruzinduko; hanyamura wuzuze igice H, I cyangwa J ukurikije ubwoko wahisemo muri C.
2. Ibyuzuzwa ni ngombwa: umugenerwabikorwa, igikorwa, findings, na recommendation nibura imwe ifite ushinzwe + deadline. Umurongo w'icyatsi hejuru ku rupapuro wa «Raporo» ukwereka ibibura.
3. Findings zigomba kuba zihariye (si amagambo rusange). Monitoring isaba nibura ifoto imwe nk'ikimenyetso.

## Report Field Types by Visit Type

### Mobilization Fields (Group III)
- Ubumenyi basanzwe bafite ku gikorwa (prior knowledge)
- Ubutumwa / Ibikorwa by'ubukangurambaga (message/activities)
- Uko bakiriye ubutumwa (message reception)
- Ubushake bwo kwitabira (1–5) (motivation/understanding)
- Ibyo basabwa gukora kugira ngo bitabire (expected actions)
- Impamvu zishobora gutuma batitabira (barriers)
- Ibyo bemeranyijweho nyuma ya mobilization (agreements)

### Monitoring Fields (Group III)
- Icyari giteganyijwe (expected)
- Icyakozwe (performed)
- Ireme ry'igikorwa (quality: Riri hejuru / Biringaniye / Rikeneye kunozwa / Riri hasi)
- Findings — Ibyagaragaye
- Itandukaniro n'impamvu (discrepancy & causes)
- Ingaruka (impact)
- Ingamba zo gukosora (na deadline n'ushinzwe) (corrective action)
- Ibipimo by'ubworozi (livestock metrics: insemination date, semen type, inspection date/result, birth date, animal number, vaccinations, records, water, shelter, hygiene)

### Follow-up Fields (Group III)
- Raporo y'ubushize (previous report reference)
- Yashyizwe mu bikorwa? (Yego / Igice / Oya)
- Inama yatanzwe ubushize (previous recommendation)
- Impamvu niba itarakozwe cyangwa yakozwe igice (reason)
- Ibyemeranyijweho bishya (igikorwa gishya) (new action)
- Ushinzwe (owner)
- Deadline (Igihe ntarengwa)
